Import dữ liệu trúng tuyển

Cách dùng: bấm “Tải file mẫu” → mở file, giữ nguyên hàng 1 (tên cột tiếng Việt), xoá dòng ví dụ rồi điền dữ liệu từ hàng 2 trở đi, mỗi hàng là 1 hồ sơ trúng tuyển.
Cách điền một số cột: Giới tính gõ Nam / Nữ; Ngày sinh và Ngày cấp CCCD theo dạng dd/mm/yyyy (ví dụ 15/03/2007); Dân tộc / Tôn giáo / Quốc tịch / Tỉnh / Xã / Phương thức / Đối tượng… gõ thẳng tên hoặc mã (ví dụ “Kinh”, “Hà Nội”) — hệ thống tự tra cứu. Cột nào không có dữ liệu thì để trống.
Kế hoạch tuyển sinh và Đợt lấy theo lựa chọn ở form, không cần trong file. Cơ sở đào tạo chọn ở ô bên dưới làm mặc định chung cho cả lần nhập — nếu trong file có điền thì giá trị trong file được ưu tiên.
