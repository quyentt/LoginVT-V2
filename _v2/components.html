0. Khuôn màn hình — CHÉP TỪ ĐÂY

Không dựng mới nếu đã có khuôn tương tự. Trước khi viết một màn, tìm khuôn giống nhất ở mục này (hoặc bảng tra nhanh trong _v2/BO-CUC.md) rồi chép về sửa. Mấy khuôn dưới đây đều đã đo trên trình duyệt thật; dựng tay lại là lặp đúng những lỗi vặt đã sửa, liệt kê ở cuối mục.

Chọn khuôn theo BẢN GỐC, không theo ý thích: bản gốc một cột thì màn mới một cột, bản gốc hai cột thì màn mới hai cột (BO-CUC.md luật 0). Mở ApisTaiChinh/Modules/<module>/html/<tên>.html của bản gốc mà đếm vùng.

A · Bản gốc MỘT cột — danh sách đầy trang

Thanh lọc ngang, bảng đầy trang, biểu mẫu thay chỗ danh sách khi thêm/sửa.

ums.crud({
    root: document.getElementById('<id trong html>'),
    title: 'Khai báo các khoản thu',      // tiêu đề trang
    formTitle: 'khoản thu',               // "Thêm <formTitle>" / "Sửa <formTitle>"
    icon: 'fa-coins',

    filters: [{ key: 'q', type: 'text', label: 'Nhập mã, tên…' }],

    list: {
        paged: true,                      // phân trang ở MÁY CHỦ như bản gốc
        call: function (f) {
            return { action: 'TC_KhoanThu/LayDanhSach', method: 'GET',
                     versionAPI: 'v1.0', strTuKhoa: f.q };
        }
    },

    columns: [ { title: 'Mã', prop: 'MA', cls: 'is-nowrap' }, … ],
    fields:  [ { key: 'strMa', col: 'MA', label: 'Mã', required: true }, … ],

    save:   function (v, row) { v.action = row ? '…/CapNhat' : '…/ThemMoi';
                                v.strId = row ? row.ID : ''; return v; },
    remove: function (ids) { return ids.map(function (id) {
                                return { action: '…/Xoa', strId: id }; }); }
});

B · Bản gốc HAI cột — danh sách trái, nội dung phải

Y như khuôn A, chỉ thêm khối master. Phần nạp / lọc / phân trang / lưu / xoá dùng lại nguyên của ums.crud — đừng viết tay lại. Cột trái tự có ô tìm chuẩn, danh sách và phân trang; cột phải là khung "Thông tin chung", đổi chỗ cho biểu mẫu khi thêm/sửa. 

ums.crud({
    … y như khuôn A …

        // empty: '…',                    // câu dẫn ở cột phải lúc chưa chọn gì

});

1. Cấu trúc

Sắp theo ITCSS, độ đặc hiệu tăng dần. Trang chỉ nạp một tệp CSS. Toàn bộ class mang tiền tố ums-, không dùng lại class nào của giao diện hiện hành và không nạp Bootstrap.

_v2/assets/css/ ├─ main.css điểm vào duy nhất, chỉ chứa @import ├─ settings/ tokens biến — không sinh ra CSS ├─ generic/ reset · fonts ├─ elements/ base thẻ HTML trần ├─ objects/ shell · grid khung và lưới, không mang màu thương hiệu ├─ components/ nav · searchbar · chip · tile · panel · button │ field · table · pager · tabs · stat · crumb ├─ vendor/ select2 · flatpickr └─ utilities/ utilities đặt cuối, luôn ghi đè được

2. Màu

Khai báo trong settings/tokens.css. Không tệp nào khác được viết mã màu.

7. Bảng

Sinh cả <table>, <thead>, <tbody> và phân trang, nên đổi giao diện bảng cho toàn hệ thống chỉ cần sửa một hàm. 

ums.ui.table({
  el: '#dTable',
  rows: DATA,
  page: { index: 1, size: 10, total: 240, onChange: reload },
  columns: [
    { title: 'Mã',         prop: 'MA', cls: 'is-nowrap' },
    { title: 'Tên',        render: r => ums.ui.cell(r.TEN, r.MOTA) },
    { title: 'Tình trạng', cls: 'is-center', render: r => ums.ui.badge(r.TTTEN, r.TT) },
    { title: 'Thao tác',   cls: 'is-actions', render: r => ums.ui.actions(r.ID) }
  ]
})

Ô đánh dấu và ô chọn một — tự vẽ, không dùng ô gốc của trình duyệt. Chỉ cần <input type="checkbox"> trần là đã đúng kiểu, kể cả ô trong bảng. Bọc trong .ums-check khi có nhãn chữ.

<label class="ums-check"><input type="checkbox" checked> Đã đánh dấu</label>
<label class="ums-check"><input type="radio" name="dm"> Chọn một</label>
